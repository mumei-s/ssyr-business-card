# S's-YR デジタル名刺

GitHub Pagesで配信する、S's-YRの仕事用デジタル名刺です。

| 名刺 | 名刺ページ | 事業内容 | 電話帳登録の案内 |
| --- | --- | --- | --- |
| 川合 伸次 | `index.html` | `works.html` | `contact.html` |
| SHINJI | `shinji/index.html` | `shinji/works.html` | `shinji/contact.html` |

どちらの名刺も「電話帳に登録」から連絡先の登録に進めます。川合 伸次版は氏名・電話・メール、SHINJI版は名前・メールを使います。

iPhoneでは名刺からvCardを直接開くよう要求し、AndroidのChromium系ブラウザには電話帳の新規登録を要求します。直接起動できない場合は、登録案内ページでダウンロード不要のGoogle コンタクトを優先し、会社・役職の手入力用に個別コピーボタンを用意しています。全項目のファイル取り込みは予備手段です。SHINJIのvCardとGoogle コンタクトのリンクは姓にSHINJIを指定します。OS側の新規登録画面の氏名分割や保存は端末で確認が必要です。

業務用の名刺と業務紹介ページでは、ポスティングとAIイラスト制作をそれぞれ15秒の説明動画で紹介しています。ポスティングは配布地域・時期・部数を、イラスト制作は画風を選ぶ回転リングの操作を紹介します。ギャラリーでは同じ海岸を描いた水彩と木版画を見比べ、それぞれを拡大できます。どちらも音声なしで、再生ボタンを押すと始まります。溶接・建築からデジタル制作までを紹介する23秒の総合映像もあります。SHINJI版は名刺下部の「仕事と作品」から業務紹介に進めます。掲載している写真・映像は業務イメージです。

SHINJI版の名刺表裏は同一の横長比率です。表面は屋号・代表者名・メールを掲載し、円形ロゴを置きません。裏面は業務内容とユーザー提供のロゴのみです。14秒周期でカラーと銀白色が滑らかに移り変わり、裏面専用のロゴ演出ON/OFFで銀白色にゆっくり固定できます。視覚効果を減らす端末設定では自動アニメーションを停止します。登録ボタンは下のお問い合わせに集約しています。

表裏の演出ON/OFFは共通で、設定を端末に保存します。SHINJI版には独立したWeb App Manifestとホーム画面追加案内を備えています。通知付き連絡は管理者専用送信画面から送信します。通常のメールアプリで送受信したメールを名刺が監視することはありません。

SHINJI名刺のMUUMEI欄には「正式公開準備中」と表示します。招待を受け取った方は、公式入口で登録を進められます。会員機能は運営の承認後に利用できます。操作体験サンプルも名刺から開けます。

名刺の通知機能が完成し、MUUMEIの正式公開・登録開始を確認した後は、名刺の通知登録者のうち受信を希望した人に、MUUMEIの招待・登録案内を管理者から一度送る方式とします。現段階では未配信です。MUUMEI会員から名刺登録者へ逆方向の自動移行は行いません。

## 事業用名刺からの個別相談

初めて開いた事業用名刺の先頭には「新着・個別チャットへのお誘い」を表示します。「名前を入力してチャットを始める」から `business-chat/` を開き、担当者に表示する名前を入力すると個別チャットで相談できます。メールアドレス・電話番号は不要です。名前の登録後はお誘いが消え、返信が届くと名刺の先頭に「新着メッセージあり」と件数が表示されます。同じ端末・ブラウザーで会話に戻れます。端末で通知を受け取りたい場合は、チャットでブラウザーの通知を許可してください。

管理者は従来の管理画面（`shinji/owner/`）で事業用の相手を選んで返信できます。事業用とSHINJI用で同じ名前を使っていても、別々の会話として扱います。

## SHINJI名刺からのチャットと管理者電話帳

- 管理画面の「名刺トップのメッセージ」から見出しと本文を掲載する。名刺のトップには見出しと短い予告が出る。「続きを読む」を押し、初めての人はSHINJIにわかる名前を入力すると、自分の個別チャットで掲載中の全文を読んで返信できる。受け取り登録済みのブラウザーでは名前の再入力を省く。掲載した本文は受け取り登録した人に共通で、返信は相手ごとの個別チャットに届く。
- 初めて名刺を開いた端末では「名刺の新着通知を受け取る」が選択済み。「続きを読む」または名前の登録時にブラウザーで通知を許可すると、掲載中の見出しとその後の新着を受け取れる。チェックを外した場合や通知を許可しなかった場合も、名刺から続きを読める。
- 渡した名刺の共通QRから、相手は「SHINJIからの連絡を受け取る」を押して、このブラウザーで個別の会話を始められる。共通QRで初めて受け取るときは、SHINJIに表示する呼び名を入力する。本文の送信やメール・電話番号の登録は不要。管理者は「チャット」で登録済みの相手を選んで最初の一通を送れる。名刺を開いただけの人は登録しない。
- 共通QRからの受け取り登録や専用リンクでの受け取りが完了すると、管理画面の「招待の受け取り」に相手の呼び名と日時が表示される。管理者がそのお知らせを開くと、対象の会話を確認できる。管理者通知をONにした端末にはプッシュ通知も届く。相手からの最初のメッセージや、相手側の通知許可は不要。
- 特定の相手に専用の入口を直接渡せるときは、「チャット」→「専用リンクで招待する」で最初のメッセージを用意し、専用QRまたはリンクを渡す。メールアドレス・電話番号の入力は不要。相手が7日以内にリンクから「チャットを開く」を選ぶと、最初のメッセージを読める。個別リンクの初回接続は1回限り。共通QRからの受け取り登録は別の会話になる。呼び名が同じでも非公開の本文を自動で紐付けない。受け取り待ちの文章は「登録した相手への下書きに使う」から、相手を確認して本文の下書きとして使える。
- 個別チャットでは差出人と端末通知のタイトルを「SHINJI」と表示する。初回登録時には返信の通知も選択済み。名刺の新着と返信の通知はそれぞれ切り替えられる。管理者の送信履歴には通知サービスの受付結果を表示する。
- 送信者は自分の吹き出しの「削除」から、その1件を双方の会話履歴から削除できる。
- 管理者は「解除済み」の会話の「一覧から消す」で、選んだ会話だけをチャット一覧から外せる。電話帳に保存した連絡先とメッセージ履歴は保持する。
- 受信者のチャットと管理者のチャット一覧には双方向の会話を表示する。電話帳は管理者がメールまたは電話番号を入力して保存した人のみ。訪問者は自動で電話帳に登録されない。連絡先が分かった場合のみ管理者が明示的に追加する。
- 管理者用 `shinji/owner/` と旧URL `shinji/owner.html` は同じ電話帳専用パスワードを使用する。管理者はログイン時に「この端末でログインを保持（30日間）」を選択できる。保持しない場合はタブ内のみ・サーバー側2時間有効。保持時もパスワードは保存せず、期限付きセッションのみを保存する。ログアウト時に解除され、別の管理者ログインで旧セッションは無効になる。管理者通知のサービスワーカーは受信者用と別のスコープを使用する。通知をタップすると管理者画面を開く。通知ON/OFF・テストは本人が操作する。
- メッセージは本人の端末と管理者だけがアクセスできる。通常のメールはOSのメールアプリで送る。通常のメール受信を監視したり、メールの送信と同時にチャット通知が配信されたと見せかけたりしない。実メールの通知連動には双方のメールサービスとの認証済み連携が必要。
- 名刺側のMUUMEI公式ページとサンプル導線はそのまま。公開案内は希望者にのみ、正式公開確認後に管理者が配信する。
- 一般登録・メッセージの回数制限、通知許可、ブロック、送信結果の区別を維持。新規契約なし。既存QRと名刺URL、MUUMEI認証・データは変更しない。
- 共有プレビューのアイコンは元の銀白ロゴから生成したPNGを全ページで指定する。

名刺と管理者ページの「ホーム画面に追加」から、ホーム画面のアイコンを消した後も追加や復元の操作に進める。管理者はログイン前から操作できる。ブラウザがインストールの確認画面を提供する場合はボタンから開き、それ以外は端末ごとの手順を表示する。相手の招待受け取りはサーバーに保存され、管理画面に再ログインして確認できる。名刺とは別の管理者用マニフェスト・サービスワーカー・アイコンを使用する。管理者通知の許可とテストはログイン後に行う。

Androidのホーム画面ドットはOS・ランチャー・PWAインストール状態の制御下にある。通知許可とドット表示は別設定。対応ブラウザーにはBadging APIで通知状態を伝える。SHINJI名刺は同じブラウザーの個別チャットに未読があれば「新着メッセージあり」と件数を表示する。名刺上の表示は通知許可・ホーム画面追加の有無を問わない。

名刺のPWAアイコンに192×192・512×512のSVGサイズを明示し、同じアプリID・起動URL・通知登録を維持する。

通信回復: 自動更新は前景操作をブロックせず、古い応答を破棄する。通知準備・権限・購読のブラウザー処理に待ち時間の上限を設ける。チャットの表示は通知処理を待たない。画面再読み込みはログイン保持・端末登録を削除しない。

## HIKARI STRAIGHT

SHINJIは管理画面の「ひかり専用ゲーム」で本人の会話を選び、受け取り日時と会話IDを確認して「この会話にゲームを許可」を押します。許可できる会話は1件です。相手の個別チャットにメッセージとゲームURLが表示されます。通知の許可は任意です。

ゲームのページはプレイ開始時にそのブラウザーの会話を照合します。許可を取り消すか別の会話に変更すると、元の会話はアクセスできなくなります。元のキャラクター、画像、必殺技、5勝の終了演出を含む配布物は暗号化されています。

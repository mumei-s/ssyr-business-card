# S's-YR デジタル名刺

GitHub Pagesで配信する、S's-YRの仕事用デジタル名刺です。

| 名刺 | 名刺ページ | 事業内容 | 電話帳登録の案内 |
| --- | --- | --- | --- |
| 川合 伸次 | `index.html` | `works.html` | `contact.html` |
| SHINJI | `shinji/index.html` | `shinji/works.html` | `shinji/contact.html` |

どちらの名刺も「電話帳に登録」から連絡先の登録に進めます。川合 伸次版は氏名・電話・メール、SHINJI版は名前・メールを使います。

iPhoneでは名刺からvCardを直接開くよう要求し、AndroidのChromium系ブラウザには電話帳の新規登録を要求します。直接起動できない場合は、登録案内ページでダウンロード不要のGoogle コンタクトを優先し、会社・役職の手入力用に個別コピーボタンを用意しています。全項目のファイル取り込みは予備手段です。SHINJIのvCardとGoogle コンタクトのリンクは姓にSHINJIを指定します。OS側の新規登録画面の氏名分割や保存は端末で確認が必要です。

業務用は名刺の下へスクロールすると営業品目、写真、紹介動画の順に閲覧できます。SHINJI版は名刺下部の仕事と作品から業務紹介に進めます。掲載している写真・映像は業務イメージです。

SHINJI版の名刺表裏は同一の横長比率です。表面は屋号・代表者名・メールを掲載し、円形ロゴを置きません。裏面は業務内容とユーザー提供のロゴのみです。14秒周期でカラーと銀白色が滑らかに移り変わり、裏面専用のロゴ演出ON/OFFで銀白色にゆっくり固定できます。視覚効果を減らす端末設定では自動アニメーションを停止します。登録ボタンは下のお問い合わせに集約しています。

表裏の演出ON/OFFは共通で、設定を端末に保存します。SHINJI版には独立したWeb App Manifestとホーム画面追加案内を備えています。通知付き連絡は管理者専用送信画面から送信します。通常のメールアプリで送受信したメールを名刺が監視することはありません。

SHINJI版の下部にはMUUMEI（会員制プライベートSNS）の紹介を常設します。公開公式ページと隔離された操作体験サンプルは登録開始前から利用できます。MUUMEIの公式設定が ready:true になったときだけ公式リンクを招待・会員登録の入口へ切り替えます。招待、本人同意、承認の条件はMUUMEI側で維持します。名刺のURLとQRコードは変更しません。

名刺の通知機能が完成し、MUUMEIの正式公開・登録開始を確認した後は、名刺の通知登録者のうち受信を希望した人に、MUUMEIの招待・登録案内を管理者から一度送る方式とします。現段階では未配信です。MUUMEI会員から名刺登録者へ逆方向の自動移行は行いません。

## 名刺からのチャットと管理者電話帳
- 名刺の「チャットで連絡する」は招待やMUUMEI会員登録不要。名前は任意、初回送信でランダムな端末キーを発行する。既存の個別リンクも利用できる。
- 受信者のチャットと管理者のチャット一覧には双方向の会話を表示する。電話帳は管理者がメールまたは電話番号を入力して保存した人のみ。訪問者は自動で電話帳に登録されない。連絡先が分かった場合のみ管理者が明示的に追加する。
- 管理者用 `shinji/owner/` と旧URL `shinji/owner.html` は同じ電話帳専用パスワードを使用する。管理者はログイン時に「この端末でログインを保持（30日間）」を選択できる。保持しない場合はタブ内のみ・サーバー側2時間有効。保持時もパスワードは保存せず、期限付きセッションのみを保存する。ログアウト時に解除され、別の管理者ログインで旧セッションは無効になる。管理者通知のサービスワーカーは受信者用と別のスコープを使用する。通知をタップすると管理者画面を開く。通知ON/OFF・テストは本人が操作する。
- メッセージは本人の端末と管理者だけがアクセスできる。通常のメールはOSのメールアプリで送る。通常のメール受信を監視したり、メールの送信と同時にチャット通知が配信されたと見せかけたりしない。実メールの通知連動には双方のメールサービスとの認証済み連携が必要。
- 名刺側のMUUMEI公式ページとサンプル導線はそのまま。公開案内は希望者にのみ、正式公開確認後に管理者が配信する。
- 一般登録・メッセージの回数制限、通知許可、ブロック、送信結果の区別を維持。新規契約なし。既存QRと名刺URL、MUUMEI認証・データは変更しない。
- 共有プレビューのアイコンは元の銀白ロゴから生成したPNGを全ページで指定する。

管理者ページではログイン前から「ホーム画面に追加」を表示する。ブラウザがインストールの確認画面を提供するときはボタンから起動し、提供しない場合は端末ごとの手順を表示する。名刺とは別の管理者用マニフェスト・サービスワーカー・アイコンを使用する。管理者通知の許可とテストはログイン後に行う。

Androidのホーム画面ドットはOS・ランチャー・PWAインストール状態の制御下にある。通知許可とドット表示は別設定。対応ブラウザーにはBadging APIで通知状態を伝え、チャット内の未読件数は別に表示する。

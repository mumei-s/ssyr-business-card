# S's-YR デジタル名刺

GitHub Pagesで配信する、S's-YRの仕事用デジタル名刺です。

| 名刺 | 名刺ページ | 事業内容 | 電話帳登録の案内 |
| --- | --- | --- | --- |
| 川合 伸次 | `index.html` | `works.html` | `contact.html` |
| SHINJI | `shinji/index.html` | `shinji/works.html` | `shinji/contact.html` |

どちらの名刺も「電話帳に登録」から連絡先の登録に進めます。川合 伸次版は氏名・電話・メール、SHINJI版は名前・メールを使います。

iPhoneでは名刺からvCardを直接開きます。AndroidのChromium系ブラウザには電話帳の新規登録を要求し、その呼び出しに対応しない端末にはGoogle コンタクトで登録する方法と手入力用の連絡先を用意しています。

裏面の「事業内容を見る」から、同じ端末で仕事や作品の紹介へ進めます。掲載している写真・映像は業務イメージです。

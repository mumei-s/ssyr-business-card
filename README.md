# S's-YR デジタル名刺

GitHub Pagesで配信する、S's-YRの仕事用デジタル名刺です。

| 名刺 | 名刺ページ | 事業内容 | 電話帳登録の案内 |
| --- | --- | --- | --- |
| 川合 伸次 | `index.html` | `works.html` | `contact.html` |
| SHINJI | `shinji/index.html` | `shinji/works.html` | `shinji/contact.html` |

どちらの名刺も「電話帳に登録」から連絡先の登録に進めます。川合 伸次版は氏名・電話・メール、SHINJI版は名前・メールを使います。

iPhoneでは名刺からvCardを直接開くよう要求し、AndroidのChromium系ブラウザには電話帳の新規登録を要求します。直接起動できない場合は、登録案内ページでダウンロード不要のGoogle コンタクトを優先し、会社・役職の手入力用に個別コピーボタンを用意しています。全項目のファイル取り込みは予備手段です。SHINJIのvCardとGoogle コンタクトのリンクは姓にSHINJIを指定します。OS側の新規登録画面の氏名分割や保存は端末で確認が必要です。

業務用は名刺の下へスクロールすると営業品目、写真、紹介動画の順に閲覧できます。SHINJI版は名刺下部の仕事と作品から業務紹介に進めます。掲載している写真・映像は業務イメージです。

SHINJI版の名刺表裏は同一の横長比率です。表面は屋号・代表者名・メールを掲載し、円形ロゴを置きません。裏面は業務内容とユーザー提供のロゴのみです。14秒周期でカラーと銀白色が滑らかに移り変わり、裏面専用のロゴ演出ON/OFFで銀白色にゆっくり固定できます。視覚効果を減らす端末設定では自動アニメーションを停止します。登録ボタンは下のお問い合わせに集約しています。
